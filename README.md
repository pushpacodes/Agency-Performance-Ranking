# Agency Performance Ranking Analysis

## Objective
To identify top and bottom performing insurance agencies using business performance metrics.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Agency Performance Ranking
5. Top and Bottom Agency Identification
6. Business Insights and Recommendations

## Key Metrics
- Written Premium Amount
- Retention Ratio
- Loss Ratio
- Policy Count

## Outcome
Developed a data-driven ranking framework to evaluate agency performance and support business decision-making.
